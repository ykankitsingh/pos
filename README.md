🇮🇳 QuickPOS India — Modern Point of Sale System
A lightweight, fully responsive, single-file Point of Sale (POS) application tailored for Indian cafes, restaurants, sweet shops, and food stalls. Built using HTML5, Tailwind CSS, and Vanilla JavaScript, it runs entirely in the browser with zero backend installation required.

✨ Features & Localization
Indian Menu Items: Pre-loaded with popular culinary items across categories like Beverages (Masala Chai, Filter Coffee, Badam Milk, Lassi), Snacks & Chaat (Samosa, Vada Pav, Pani Puri), Meals (Masala Dosa, Chole Bhature, Paneer Rolls), and Sweets (Gulab Jamun, Jalebi).

Currency (₹): All calculations, inputs, and receipts use Indian Rupees (₹).

Indian Tax Structure: Built with an integrated 5% GST calculation standard for standard dining/food outlets.

UPI & QR Code Payments: Features a dedicated UPI / QR code payment modal simulator alongside Cash (with change-due calculation) and Card/Wallets.

Thermal Bill / Receipt Generator: Automatically formats a standardized Indian restaurant receipt complete with GSTIN, FSSAI license placeholder, order token number, and a direct Print Bill option.

Zero Dependencies (CDN-based): Uses Tailwind CSS and FontAwesome via CDN. Just save and run!

🚀 How to Run
Copy the HTML code provided in the previous response.

Create a new file on your computer and name it index.html.

Paste the code into index.html and save the file.

Double-click index.html to open it in any modern browser (Chrome, Edge, Safari, Firefox).

🛠️ Tech Stack
Frontend Framework / Styling: Tailwind CSS (via CDN)

Icons: FontAwesome 6.4.0

Core Logic: Vanilla JavaScript (ES6+)
